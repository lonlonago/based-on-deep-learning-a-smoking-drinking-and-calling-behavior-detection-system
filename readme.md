# Based on deep learning, a smoking, drinking and calling behavior detection system (YOLOv8+)

## Body

Based on the advanced YOLOv8 object detection algorithm, this project has developed a smart visual system specifically for detecting smoking, drinking, and calling behaviors. The system is designed to recognize and classify three types of specific human behaviors: smoking (smoke), drinking (drink), and calling (phone). The dataset used in this project includes 3507 images, with 3157 training images, 350 validation images, and achieves efficient recognition of these specific human behaviors through deep learning techniques. This system can be deployed on various computing platforms, including edge devices and cloud servers, and it has real-time detection capabilities, high accuracy, and rapid response. The project not only completes the entire process of model training and validation but also optimizes the system for practical application scenarios, ensuring stable detection performance in complex environments.
